# Security and privacy

Ownference Mac uses Apple's on-device SystemLanguageModel. It has no cloud fallback, prompt-history database, arbitrary model tools or web-facing listener. Generated output is untrusted: inspect it before copying or saving. Other applications can read text you deliberately place in their contexts.

Apple Intelligence device/configuration, language/region, safety and acceptable-use requirements apply. The app is not a sandbox against a compromised Mac. Release ZIPs are ad-hoc signed, not Developer ID signed or notarized; no instructions to bypass Gatekeeper are supported.

Report vulnerabilities privately to the repository owner before disclosing sensitive details. Never post credentials, personal documents or private prompts in public issues. Include OS/build, model availability and sanitized reproduction steps. No security certification is claimed.
