# Contributing

Use Swift with the macOS26 SDK. Read AGENTS.md, run the semantic tests and build, and exercise actual native controls for UI changes. Use a focused branch and conventional commit subject; describe user-visible behavior, privacy implications and observed verification in the PR.

A model fixture is not proof of Apple inference. Only report a live model/UI smoke as passed when it actually ran. Preserve Node-free local operation, opt-in login and shared family branding. No credentials or private prompts in issues. Contributions use Apache-2.0. See docs/testing.md and SECURITY.md.
